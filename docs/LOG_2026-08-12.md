# LOG 2026-08-12 — sesja 1: cały projekt od zera

## Co powstało
Kompletne narzędzie: import → bake atlasu → LOD-y → export FBX/GLB + viewer/GUI
+ CLI + portable exe. Wszystko w jednej sesji, zweryfikowane testami i importem UE.

## Stan na koniec sesji
- `dist\Lodziarz.exe` — 64 MB onefile, działa z czystego katalogu (testowane)
- UE 5.6 headless import: `test_glass.fbx` → 1 StaticMesh, num_lods=4,
  tris=[1292, 646, 322, 160] — LODGroup wchodzi automatycznie jednym plikiem
- viewer zweryfikowany Playwrightem (screenshoty: LOD switching, wireframe,
  bake szkła z opacity, UV flat)

## Kluczowe decyzje techniczne
1. **FBX export = sidecar `fbx_writer.exe`** (Autodesk FBX SDK 2020.3.4,
   kod LODGroup przeniesiony 1:1 z Brutgen `export/src/fbx_export.cpp`).
   Autodesk nie ma python bindings na PyPI. Python pisze format LZMESH
   (spec w komentarzu `native/fbx_writer.cpp`), sidecar składa scenę.
2. **meshoptimizer nie istnieje na PyPI** → `meshoptimizer.dll` kompilowany
   ze źródeł (`third_party/meshoptimizer-0.25`), ctypes w `lodziarz/meshopt.py`.
3. **Toolchain natywny jak w Brutgen**: VS BuildTools 18
   (`g:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools`), CMake+Ninja,
   **/MD** (libfbxsdk-md wymaga; /MT = LNK2038). Build: `native\build_native.ps1`.
4. **UV wewnętrznie GL** (origin dolny-lewy); do glTF flip V (`exporter/glb.py`).
   Bez flipa materiały "zamieniają się miejscami" na modelu (V odwrócone).
5. **xatlas nie zachowuje kolejności trójkątów** → tri_material odtwarzany
   mapą wierzchołek→materiał, majority z 3 rogów (`atlas.py`).
6. **GLB pisany ręcznie pygltflib** (nie trimesh) — bo TEXCOORD_1 (stare UV
   do podglądu) i opacity w alfie base color.
7. Normalki w bake: re-enkodowanie stary TBN → world → nowy TBN (tangenty
   liczone dla obu zestawów UV w `core.compute_tangents`).

## Pułapki ufbx 0.0.5 (python binding) — NIE RUSZAĆ wzorca w importer.py
- `node.parent` / `node.children` → access violation (zepsute wrappery)
- po `scene.nodes` iterować wolno tylko RAZ; głęboki dostęp w trakcie
  iteracji unieważnia iterator
- destruktor sceny przez GC z żywymi wrapperami = AV → jawne
  `collected.clear(); gc.collect(); scene.free()`
- tajemnicze "exit code 5" przy poprawnym output = crash przy teardown
- `ufbx.Matrix` ma kolumny `c0..c3` (nie `.cols`)
- skip LOD-ów źródłowych: po nazwach `<Grupa>_LOD<n>` (attrib_type 16 = grupa)

## Znane ograniczenia
- **meshoptimizer vs flat-shaded hard-surface**: narożniki z 3+ duplikatami
  wierzchołków (split po normalach/UV) = locked → budynek Brutgena redukuje
  się ~3%. Smooth/photogrammetry OK (torus 9216→1152 idealnie wg ratio).
  Ewentualny przyszły feature: tryb smooth-weld przed simplify.
- backendy bake `raycast` i `cameras26` = stuby z TODO
- viewer drag&drop: tylko PNG/JPG/WebP (browser); pipeline przyjmuje
  wszystko co Pillow (PNG/JPG/TGA/BMP/TIFF/WebP + embedded FBX)
- OBJ z `d`/`Tr` (dissolve) nieobsłużone (opacity tylko z PBR/glTF/FBX)
- FBX: opacity nie jest podpinane do materiału Phong (plik `T_*_Opacity`
  leży obok; LZMESH ma 4 sloty tekstur)

## Testy / workflow weryfikacji
- test assety: `testdata\` (test_crate.obj 2 materiały+normal mapa,
  test_torus.glb 9216 tri, test_glass.glb box+szklana sfera alpha 0.3)
- wyniki: `testout\` (brutgen/ = przetworzony BLD_spine_1_merged.fbx)
- viewer testowany Playwright MCP: serwer `start_server(port)` w tle,
  `window.lodziarzLoadModel('/out/plik.glb')` do ładowania bez GUI
- UE verify: `scratchpad\ue_test\` (Test.uproject z PythonScriptPlugin +
  import_test.py). Komenda:
  `UnrealEditor-Cmd.exe Test.uproject -run=pythonscript -script=... -stdout
   -unattended -nopause -nosplash -nullrhi`
  UWAGA: `print()` nie trafia do loga — używać `unreal.log_warning()`.
  Property: `import_mesh_lods` (nie `import_mesh_lo_ds` — deprecated).

## Komendy
```powershell
# build natywny (fbx_writer.exe + meshoptimizer.dll -> lodziarz\bin)
powershell -File native\build_native.ps1
# exe
.venv\Scripts\pyinstaller.exe lodziarz.spec --noconfirm   # -> dist\Lodziarz.exe
# dev bez exe
.venv\Scripts\python.exe -m lodziarz.cli process testdata\test_torus.glb -o testout\t
.venv\Scripts\python.exe -m lodziarz.cli gui --browser
```
